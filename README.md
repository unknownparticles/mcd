# 🍟 麦门今日签 · McDaily Sign

> **"今天吃什么"不该是选择题，是一次抽签。**
> 同一天、同一个 MBTI，全国抽到同一支签。明天，签就换了。

「麦门今日签」是基于 **麦当劳 MCP** 的**每日签运产品**：你的人格 + 当天天气 + 节气节日 + 实时菜单与真实优惠券，经确定性算法抽出一张「今日签」——签位、签文、真实券后价、一键下单，全链路真实。

## 🔥 钩子：为什么明天还会来

1. **一人一签** — 引擎用「日期 × MBTI × 城市 × 口味偏好 × 设备盐」做确定性哈希微扰：同一天你和朋友抽到的签不同，第二天全部重置。签是当天的私人暗号，不是随机推荐，**明天签就变了**，天然回访钩子
2. **限定签收集图鉴** — 24 节气 + 节日会出现限定签（霜降签、程序员节签……），抽到自动收入签册，一年 38 枚，收齐是一种修行
3. **麦龄 streak** — 连续求签天数 + 累计签数，首页常驻
4. **分享签卡** — 一键 canvas 生成签纸风分享图（人格/签位/签文/到手价），发群即传播
5. **添香火** — Star 按钮做成了世界观内的动作

## ✨ 与其他参赛作品的差异化

市面多数作品是**工具**（省钱计算器、营养配餐、点餐决策）——解决一次问题，用完即走。
麦门今日签是**内容**：它每天生产一份全国同步的人格化签运，把"麦当劳怎么吃"变成每天可以讨论、收集、炫耀的社交话题。工具没有明天，签有。

## 🚀 快速开始

### 在线体验（无需安装）

**https://alunapp.cn/mcd/** — GitHub Pages 静态演示版：求签、铸卡、分享签卡、交换全程可玩（内置门店真实菜单快照）；填入自己的 DeepSeek Key 后签文由 AI 现写。真实下单需要本地启动带 MCP Token 的服务。

### Web 版

```bash
# 1. 配置麦当劳 MCP Token（https://open.mcd.cn/mcp 申请）
export MCD_TOKEN="你的token"
# 或写入 ~/.workbuddy/mcp.json 的 mcd-mcp 配置（服务端会自动读取）

# 2. 启动（零第三方依赖，Node 18+）
node web/server.js
# 打开 http://localhost:8787
```

### WorkBuddy Skill 版

把 `skill/mcdaily-sign/` 安装到 WorkBuddy 技能目录（`~/.workbuddy/skills/`），在对话里直接说：

> "我是 INTJ，今天中午在厦门观音山，帮我抽个麦当劳签"

Skill 会输出：签位 + 签文 + 真实券后价 + 是否下单（下单前强制二次确认）。

## 🤖 AI 签文（可选 · DeepSeek）

签文默认由内置规则生成，零配置可用。想让它变成真正的「现写」：

1. 页面右上角 **设置 → AI 签文 · DeepSeek**，粘贴自己的 API Key（[platform.deepseek.com](https://platform.deepseek.com) 获取）
2. 选模型：`deepseek-chat`（快）或 `deepseek-reasoner`（更会写）
3. 点「测试连接」验证，之后每次求签签文由 DeepSeek 现写，签纸下方标注 `AI 签文 · deepseek-chat`

实现要点：

- **Key 只存本机** `localStorage`，浏览器直连 `api.deepseek.com`（该接口开放 CORS），不经过本站服务器，也不会上传到仓库
- **兜底不阻塞**：401/402/429/网络异常一律静默回退规则签文，只弹一句提示，不影响铸卡与分享
- **提示词**：把 MBTI 人格、天气、节气/节日、当日签位与匹配度、奇门八门心态一起喂给模型，要求 70–95 字白话新中式签文，结尾给一个具体小动作
- **静态托管同样可用**：Pages 版没有后端，AI 调用在浏览器完成，所以填 Key 即可用

## 🔒 安全设计

- **AI 不碰钱**：AI 只生成待支付订单，支付永远由用户本人在微信/官方渠道完成
- **下单二次确认**：页面上必须确认后才会调 `create-order`
- **Token 隔离**：Web 版 Token 仅存服务端（环境变量或 WorkBuddy 配置），不进前端
